# LinuxEnvConfig

Ubuntu / Debian / Kali Linux 基础环境配置脚本

## 功能

1. 启用root用户
2. 启用SSH服务
3. 允许root用户SSH登录
4. 获取当前主机网卡及IP地址信息
5. 配置APT镜像源
6. 安装Miniconda3
7. 卸载Miniconda3
8. 安装Docker
9. 卸载Docker
10. 配置Docker为国内镜像
11. 安装Docker-compose
12. 卸载Docker-compose
13. 安装Metasploit-framework
14. 卸载Metasploit-framework

## 使用

```bash
git clone https://gitee.com/yijingsec/LinuxEnvConfig.git

cd LinuxEnvConfig

bash LinuxEnvConfig.sh
```
