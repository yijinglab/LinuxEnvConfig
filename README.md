# LinuxEnvConfig

Ubuntu / Debian / Kali Linux 基础环境配置脚本

```
 ─────────────────────────────────────────────────────

    *************  LinuxEnvConfig  *************

    适配系统: Ubuntu / Debian / Kali (基于Debian)
    脚本作用: Linux 基础环境配置

                --- Made by mingy ---

 ─────────────────────────────────────────────────────
```

## 使用

```bash
git clone https://gitee.com/yijingsec/LinuxEnvConfig.git

cd LinuxEnvConfig

sudo bash LinuxEnvConfig.sh
```
